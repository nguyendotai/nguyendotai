### 📋 NDT Task — Task Management SaaS (Full-stack)

> Ứng dụng quản lý công việc kiểu Jira/Trello (Workspace → Board → Task), hỗ trợ cả Kanban lẫn Scrum (Sprint, Burndown/Velocity Chart). Đăng nhập Email/Google + xác thực 2 lớp (2FA TOTP), phân quyền Owner/Admin/Member theo Workspace, đồng bộ realtime qua Socket.IO, Time Tracking, Notification, Activity Log, tìm kiếm toàn hệ thống.

**🔗 Demo:** [ndt-task-frontend.vercel.app](https://ndt-task-frontend.vercel.app)

| Repo | Vai trò |
| :--- | :--- |
| [NDT-Task-Backend](https://github.com/nguyendotai/NDT-Task-Backend) | NestJS REST API — MongoDB (Prisma), Redis (BullMQ), Socket.IO |
| [NDT-Task-Frontend](https://github.com/nguyendotai/NDT-Task-Frontend) | Next.js — giao diện quản lý công việc |
